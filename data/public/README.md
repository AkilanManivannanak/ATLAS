# Public reference data

Published aggregate statistics used to check the synthetic generator against the real US payment system.
These are system-wide totals from the operators' own pages. They contain no bank-level or payment-level data.

| File | Source | Retrieved |
|---|---|---|
| `fedwire_funds_annual.csv` | Federal Reserve Financial Services, Fedwire Funds Service annual statistics, https://www.frbservices.org/resources/financial-services/wires/volume-value-stats/fedwire-funds-service-annual-statistics/ | 2026-11-16 |
| `fednow_quarterly.csv` | Federal Reserve Financial Services, FedNow Service quarterly volume and value statistics, https://www.frbservices.org/wp-content/uploads/20261020-quarterly-3q2026-fednow-ascii.txt (value converted from dollars to millions, one decimal) | 2026-11-16 |
| RTP figures in `atlas.calibration` | Federal Reserve Bank of Richmond, Economic Brief 26-28 (Aug 2026): about 128 million payments and $480 billion in Q1 2026, about $3,750 each | 2026-11-16 |
